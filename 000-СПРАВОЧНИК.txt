СПРАВОЧНИК — Тренажер знаний ГЦО, полный проект (объединённая версия)
========================================================================

Это ЕДИНЫЙ актуальный набор — базовый проект + обновление «база знаний»
уже объединены, дублей нет. Не нужно больше грузить старые наборы
(ни первые 47 файлов, ни отдельно «Этап 1») — используйте только этот.

Если вы уже начали грузить файлы из старых наборов — не страшно, просто
продолжайте этим списком и при совпадении имени файла на GitHub нажимайте
"заменить"/перезаписывайте содержимое.

Как использовать:
1. На GitHub: "Add file" -> "Create new file".
2. В поле имени файла вводите РЕАЛЬНЫЙ путь из списка справа (например
   src/app/layout.tsx) — GitHub сам создаст нужные папки.
3. Откройте скачанный файл (001.txt и т.д.), скопируйте весь текст,
   вставьте в тело файла на GitHub.
4. Commit new file. Повторите для каждого файла.

Папки с круглыми скобками "(admin)" и квадратными "[id]" — это нормальный
синтаксис Next.js, вводите их как есть, это не опечатка.

Начните с этих файлов — это ядро проекта:
- 004.txt => package.json
- 005.txt => prisma/schema.prisma
- 006.txt => prisma/seed.ts

После загрузки всех файлов, у себя на компьютере (там, где база данных):

  npm install
  npx prisma migrate dev --name init
  npx prisma db seed

Последняя команда создаст суперадминистратора с логином javokhir и
покажет временный пароль ОДИН РАЗ в консоли — сразу его запишите.
