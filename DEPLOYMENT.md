# Пошаговая инструкция: GitHub + Supabase + Vercel

Физические шаги — куда заходить, что нажимать, что загружать.

## Два этапа запуска

**Этап 1 — сайт без ИИ (делаем сейчас).** Вопросы создаются вручную через
`/admin/questions/new`, открытые ответы проверяются простым совпадением по
ключевым словам (`GRADING_MODE=keyword` в `.env` — это значение по умолчанию,
можно вообще не указывать). `ANTHROPIC_API_KEY` для этого этапа НЕ нужен.

**Этап 2 — подключаем ИИ (позже).** Меняете в `.env` / в Vercel одну переменную
`GRADING_MODE=ai`, добавляете `ANTHROPIC_API_KEY` — и открытые ответы начинают
проверяться Claude (смысл + орфография + грамматика), а на `/admin/materials`
можно загружать документы и генерировать вопросы автоматически. Код менять не нужно.

## Шаг 1. GitHub — репозиторий

1. Зайти на https://github.com → войти в свой аккаунт (это будет владелец репозитория, как требует раздел 24 ТЗ).
2. Нажать зеленую кнопку **New** (или "+" → "New repository").
3. Название: например `gco-trainer`. Приватность: **Private** (рекомендуется, пока проект не готов к показу всем).
4. Нажать **Create repository**.
5. На своём компьютере — распаковать присланный архив `gco-trainer-scaffold.zip` в папку.
6. В терминале внутри этой папки выполнить:
   ```
   git init
   git add .
   git commit -m "Initial scaffold"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/gco-trainer.git
   git push -u origin main
   ```
   (GitHub сам покажет эти команды на странице только что созданного репозитория — можно скопировать оттуда.)

## Шаг 2. Supabase — база данных

1. Зайти на https://supabase.com → **Start your project** → войти (можно через GitHub).
2. **New project** → указать название (например `gco-trainer-db`) и пароль базы данных (сохранить его — понадобится).
3. Подождать 1-2 минуты, пока Supabase создаст проект.
4. Зайти в раздел **Project Settings → Database**.
5. Найти строку **Connection string** → выбрать вариант **URI** (не Session mode) → скопировать. Она выглядит так:
   ```
   postgresql://postgres:[ВАШ-ПАРОЛЬ]@db.xxxxx.supabase.co:5432/postgres
   ```
6. Это и есть значение для `DATABASE_URL`.

## Шаг 3. Применить схему базы данных

На своём компьютере, в папке проекта:

1. Создать файл `.env` (скопировать `.env.example` и переименовать).
2. Вставить туда `DATABASE_URL` из Supabase (шаг 2.5) и `ANTHROPIC_API_KEY` (ваш ключ Anthropic API).
3. Выполнить:
   ```
   npm install
   npx prisma migrate dev --name init
   npx prisma db seed
   ```
   Первая команда создаст все таблицы (`User`, `Material`, `Question`, `TestAttempt` и т.д.) внутри Supabase.
   Вторая — создаст единственного Суперадминистратора (`mirkomilovjavohir562@gmail.com`).
4. Проверить: зайти в Supabase → **Table Editor** — там должны появиться все таблицы.

## Шаг 4. Vercel — деплой сайта

1. Зайти на https://vercel.com → войти через GitHub.
2. **Add New → Project**.
3. Выбрать репозиторий `gco-trainer` из списка (он появится, т.к. вы вошли через тот же GitHub-аккаунт).
4. Vercel сам определит, что это Next.js — ничего менять не нужно на этом экране.
5. Развернуть блок **Environment Variables** и добавить (для этапа 1 без ИИ — только первые три):
   - `DATABASE_URL` — та же строка из Supabase
   - `NEXTAUTH_SECRET` — любая случайная строка (можно сгенерировать на https://generate-secret.vercel.app/32)
   - `FEEDBACK_EMAIL` = `mirkomilovjavohir562@gmail.com`
   - (позже, для этапа 2) `GRADING_MODE` = `ai`, `ANTHROPIC_API_KEY`, `AI_PROVIDER` = `anthropic`
   - (позже) `NEXTAUTH_URL` — адрес сайта, когда включите авторизацию
6. Нажать **Deploy**. Через 1-2 минуты сайт будет доступен по адресу вида `gco-trainer.vercel.app`.

## Шаг 5. Дальнейшие изменения (как вы и делали раньше)

- Меняете код локально или прямо в GitHub (веб-редактор файла подойдёт для мелких правок).
- `git push` (или сохранение файла на GitHub) → Vercel **автоматически** пересобирает и обновляет сайт.
- Supabase при этом не трогается — данные сотрудников остаются на месте.
- Если поменяли `prisma/schema.prisma` (добавили новое поле/таблицу) — обязательно локально прогнать
  `npx prisma migrate dev --name имя_изменения` и запушить и папку `prisma/migrations`, иначе на Vercel
  база не будет знать о новых полях.

## Первая проверка после деплоя

1. Открыть `https://ваш-сайт.vercel.app` → ввести имя → «Начать обучение».
2. Открыть `https://ваш-сайт.vercel.app/admin/materials` → загрузить один тестовый документ (PDF/DOCX/TXT).
3. Нажать «+ BEGINNER» → убедиться, что появились сгенерированные вопросы.
4. Пройти уровень Beginner от лица сотрудника — проверить начисление конфет и результат.
